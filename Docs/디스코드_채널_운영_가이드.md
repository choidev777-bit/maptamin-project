# 🎮 맵타민 디스코드 채널 운영 가이드

---

## 📢 #공지

### 용도
- 확정된 의사결정 사항 공유 (서비스 방향, 가격 정책 변경 등)
- 중요 문서 공유 (계약서 최종본, 사업자등록증, 정산 내역서 등)
- 공용 계정 정보 공유 (AI 구독 계정, 키워드 분석 툴 로그인 정보 등)
- 서비스 장애·점검 공지

### 운영 규칙
- **갑(대표)만 작성** — 을(프리랜서)은 읽기 전용
- 모든 공지는 **메시지 고정(Pin)** 처리
- 잡담이나 논의는 이 채널에서 하지 않음 (스레드도 자제)

### 작성 예시
```
📢 [공지] 2026.03.10

맵타민 구독 가격을 4월 1일부터 아래와 같이 변경합니다.
- 베이직: 월 29,000원 → 월 33,000원
- 프로: 월 59,000원 → 월 66,000원

기존 고객에게는 3월 20일까지 이메일로 사전 안내 예정.
CS 문의 시 "기존 고객은 1개월간 기존 가격 유지"로 안내 부탁드립니다.
```

## 📋 #업무-브리핑-및-보고

### 용도
- **매주 1회** 주간 업무 브리핑 보고
- **매월 말일** 월간 업무 종합 보고
- 매출·비용 정산 내역 공유 (갑 → 을)

### 운영 규칙
- 주간 보고는 **매주 금요일**까지 작성 (요일은 상호 협의 후 변경 가능)
- 월간 보고는 **매월 말일**까지 작성
- 보고서에 대한 피드백은 **스레드(Thread)**에서 진행
- 갑은 월간 보고에 대해 **7일 이내** 검토 완료 (무응답 시 승인 간주)

## 💡 #기획-및-피드백

### 용도
- 블로그 원고 초안, 유튜브 대본/썸네일 시안 등 **검토가 필요한 자료** 업로드
- 마케팅 아이디어, 이벤트 기획안 제안
- 갑(대표)의 승인이 필요한 항목 요청

### 운영 규칙
- 자료를 올릴 때 **한 줄 설명**을 반드시 함께 작성
- 피드백과 수정 요청은 반드시 **스레드(Thread)**에서 진행
- 최종 승인 시 갑이 ✅ 이모지로 반응

### 작성 예시
```
💡 [블로그 원고 검토 요청] 03.10

제목: "네이버 플레이스 순위, 왜 매일 바뀔까?"
타겟 키워드: 네이버 플레이스 순위, 플레이스 노출
예상 발행일: 03.12(수)

📎 원고 파일 첨부 (또는 노션 링크)

확인 부탁드립니다!
```

**→ 대표가 스레드에서:**
```
✅ 승인합니다. 2번째 소제목만 좀 더 구체적으로 수정해주세요.
```

## 🚨 #CS-이슈-공유

### 용도
- 친구(을) 혼자 판단하기 어려운 **CS 특이 케이스** 공유
- 환불/항의/법적 문의 등 **대표 확인이 필요한 건**
- CS 대응 매뉴얼에 없는 새로운 유형의 문의

### 운영 규칙
- 고객 개인정보(이름, 전화번호 등)는 가능한 가려서 공유
- 긴급도에 따라 이모지 표시: 🔴 긴급 / 🟡 보통 / 🟢 참고
- 대표 확인 후 처리 방향이 결정되면 스레드에 기록

### 작성 예시
```
🚨 [CS 이슈] 03.10 🔴긴급

고객: 김OO (카카오톡 채널)
문의 내용: "결제했는데 서비스가 안 보여요. 
          환불해주세요."
현재 상태: 결제 확인됨, 계정에 구독 미반영

📎 카카오톡 대화 캡처 첨부

→ 기술적 오류로 보입니다. 대표님 확인 부탁드립니다.
```

## 💬 #일반-잡담

### 용도
- 업무 외 가벼운 대화
- 재미있는 마케팅 레퍼런스, 경쟁사 동향 공유
- 점심/저녁 약속, 오프라인 미팅 일정 조율

### 운영 규칙
- **업무 지시나 중요한 의사결정은 이 채널에서 하지 않기**
- 편하게 자유롭게 소통

## 🔊 일반 (음성 채널)

### 용도
- 주간 대면/비대면 미팅 시 사용
- 급한 안건이 있을 때 빠르게 음성 통화
- 화면 공유하며 콘텐츠 함께 검토

### 운영 규칙
- 상호 협의 하에 접속 (일방적으로 호출하지 않기)
- 회의 결과는 반드시 `#업무-브리핑-및-보고` 또는 `#공지`에 텍스트로 기록

## 📌 디스코드 운영 총정리

| 채널 | 누가 주로 쓰나 | 핵심 용도 |
|------|--------------|----------|
| 📢 공지 | 갑(대표) | 확정된 결정사항, 중요 문서 |
| 📋 업무-브리핑 | 을(프리랜서) | 주간/월간 보고 |
| 💡 기획-피드백 | 을 → 갑 승인 | 원고·기획안 검토 요청 |
| 🚨 CS-이슈 | 을 → 갑 확인 | 혼자 판단 어려운 CS 건 |
| 💬 일반-잡담 | 둘 다 | 사적 대화, 가벼운 공유 |
| 🔊 음성 | 둘 다 | 주간 회의, 긴급 통화 |

### 🔑 3가지 핵심 규칙
1. **업무 지시·승인은 반드시 텍스트 채널에 기록** (음성으로만 결정하지 않기)
2. **하나의 주제에 대한 논의는 스레드(Thread)를 활용** (채널을 깔끔하게 유지)
3. **파일명에 날짜 붙이기** (예: `240310_주간보고_박형준`)
