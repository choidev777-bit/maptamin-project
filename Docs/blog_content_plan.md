# 맵타민 공식 블로그 콘텐츠 플랜

> **Last Updated**: 2026-03-20  
> **블로그**: 네이버 공식 블로그  
> **목표**: 자영업 사장님 유입 → 맵타민 인지 → 가입 전환

---

## 콘텐츠 전략 개요

```
[1단계] 기반 구축 (1~2번 글)
  → 서비스 소개 + 핵심 교육 콘텐츠. 동시 발행.

[2단계] 검색 유입 (3~7번 글)
  → 사장님들이 실제 검색하는 키워드를 타겟한 교육 콘텐츠.
  → 글 끝에서 자연스럽게 맵타민 연결.

[3단계] 신뢰 구축 (8~10번 글)
  → 사용법 가이드, 활용 사례, 비교 분석.
  → "써볼까?" 단계의 독자를 전환.
```

## 2단계: 검색 유입 콘텐츠 (1주 1~2편 페이스)

### 📌 3번 글 — "상위노출" 키워드 공략

| 항목 | 내용 |
|------|------|
| **제목** | 네이버 플레이스 상위노출, 순위는 대체 어떻게 정해지는 걸까? |
| **타겟 키워드** | 네이버 플레이스 상위노출, 플레이스 순위 올리는 법 |
| **핵심 내용** | ① 네이버 공식 정책 기반 순위 결정 요인 정리 (인기도, 관련성, 신뢰도) ② "어뷰징은 왜 안 되는가" (네이버 정책 링크) ③ 정공법: 리뷰, 사진, 영업정보 최적화 ④ "그런데 이 작업이 효과가 있는지 어떻게 아나요?" → 맵타민 연결 |
| **AEO 즉답** | "네이버 플레이스 순위는 인기도, 관련성, 신뢰도 3가지 요소로 결정됩니다." |
| **태그** | 플레이스상위노출, 네이버플레이스, 플레이스마케팅, 플레이스순위 |

## 전체 콘텐츠 퍼널

```
[사장님이 검색] "네이버 플레이스 상위노출"
        ↓
[3번 글] 상위노출 원리 교육
        ↓ (글 하단 링크)
[2번 글] "근데 순위가 위치마다 다른 거 아셨나요?"
        ↓ (글 하단 링크)
[1번 글] "이걸 해결하는 서비스가 맵타민입니다"
        ↓ (CTA)
[maptamin.com] 가입 → 온보딩 → 첫 리포트
```

> **핵심 원칙**: 2~7번 글로 사장님을 데려오고, 1번 글과 8~10번 글로 전환시킨다.
