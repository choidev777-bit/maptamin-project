# 맵타민(Maptamin) 셀링 포인트 & USP 리스트

---

## 1\. 핵심 USP (Unique Selling Proposition)

### ⬛ "한국 최초, 네이버 지도 기반 \[플레이스 순위 지도\]"

상권 내 수십 개 좌표에서 내 매장의 네이버/구글 플레이스 순위를 측정하고, 지도 위에 색상(초록/노랑/빨강)으로 시각화하는 도구

- **기존 순위 추적 도구** (애드랭크, 캐치랭크 등): "건대 카페" 같은 지역명 키워드의 고정 순위 숫자 1개만 제공  
- **맵타민**: 상권 전체에서 "카페"라는 업종 키워드의 **위치별 순위 분포**를 지도 위에 시각적으로 제공

## 2\. 셀링 포인트 상세 리스트

### ⬛ SP1. 지역명 키워드 순위의 "근본 원인"을 보여준다

**한 줄 요약:** "건대와인바 38위" — 왜 38위인지 이유를 알 수 있는 유일한 도구

**설명:**

- 네이버 플레이스는 상권 내 어디서 검색해도 순위가 높은 매장을 "지역 대표 매장"으로 인식  
- 지역명 키워드("건대 카페") 순위는 업종 키워드("카페") \[플레이스 순위 지도\]의 결과물  
- 맵타민은 업종 키워드가 상권 내에서 어떻게 분포하는지 보여줌으로써, 지역명 키워드 순위가 낮은 근본 원인을 진단

**대표 사례:**

- 질서정연: "건대와인바" 38위이지만, "와인바" 업종 \[플레이스 순위 지도\]은 평균 8.9위 → 기반은 있으므로 투자 가치 있음  
- 노우즈 창덕: "서순라길카페" 27위이고, "카페" 업종 \[플레이스 순위 지도\]은 평균 71위/전체 미노출 → 현재 투자 가치 낮음

### ⬛ SP2. 어떤 키워드에 투자하고, 어떤 키워드를 버려야 하는지 판단 기준을 제공한다

**한 줄 요약:** 마케팅 예산의 낭비를 막는 키워드 전략 의사결정 도구

**설명:** 

- 경쟁사들(애드랭크, 캐치랭크)은 지역명 키워드의 순위 숫자만 추적합니다.

- "건대카페 38위" → 낮네, 근데... 그래서요? 더 투자해야 하나요, 포기해야 하나요?  
  이 질문에 경쟁사 도구는 답을 줄 수 없습니다. 숫자만 알려줄 뿐입니다.  
  맵타민은 업종 키워드의 상권 분포를 보여주기 때문에:

- "건대카페 38위"인데 "카페" 노란불/빨간불 → 네이버가 이미 카페로 인식 중 → 집중할 키워드  
- "건대카페 38위"인데 "카페" 전체 빨간불/미노출 → 네이버가 전혀 카페로 인식 못함 → 지금 당장 버릴 키워드  
- 이 판단을 내릴 수 있는 근거 데이터를 제공하는 것은 맵타민뿐입니다.

**판단 프레임워크:**

| 업종 키워드 \[플레이스 순위 지도\] 상태 | 지역명 키워드 순위 | 판단 |
| :---: | :---: | :---: |
| 상권에서 인식됨 (노란\~초록불) | 낮아도 OK | ✅ **집중 키워드** — 기반이 있으므로 투자하면 올라감 |
| 상권에서 미인식 (올빨간불/미노출) | 낮음 | ❌ **보류 키워드** — 기반이 없으므로 투자 효율 낮음 |
| 상권에서 잘 인식됨 (초록불 다수) | 이미 상위 | 🏆 **유지 키워드** — 현상 유지 모니터링 |

### ⬛ SP3. 네이버 지도 앱 시대의 필수 도구

**한 줄 요약:** "내 근처 맛집" 검색하는 즉시 구매 고객에게 내 가게가 보이는지 확인하는 유일한 방법

**설명:**

- 트렌드: 사람들이 네이버 검색창보다 **네이버 지도 앱**에서 먼저 검색  
- 지도 앱 검색 \= "내 근처 맛집", "주변 미용실" 같은 **업종 키워드** 사용  
- 이 검색은 **검색자의 GPS 위치에 따라 결과가 완전히 다르게** 나옴  
- 지도 앱 사용자 \= 구매 의사 100%에 가까운, 가장 가치 있는 고객  
- 기존 도구: 이 위치별 순위 변동을 추적 불가  
- **맵타민**: 상권 내 어느 위치에서 검색해도 내 가게가 보이는지를 \[플레이스 순위 지도\]으로 즉시 확인

---

### ⬛ SP4. 약한 지역(동네)을 찾아 타겟 마케팅의 방향을 제시한다

**한 줄 요약:** "어디에 마케팅 비용을 쓸지"를 지도 위에서 데이터로 보여주는 도구

**설명:**

- \[플레이스 순위 지도\]의 빨간불/노란불 좌표 \= 해당 위치에서 검색했을 때 내 매장 순위가 낮은 곳  
- 각 좌표는 실제 지도 위에 찍히므로, 어느 동네(방향)가 약한지 직관적으로 파악  
- 약한 지역의 트래픽(플레이스 방문, 체류, 저장, 길찾기)을 늘려야 해당 지역 순위 상승  
- 네이버 플레이스 광고의 지역 타겟팅, 네이버 지역소상공인 광고 지역 타겟팅, 당근마켓 동네 광고, 블로그 세부 지명 활용 등으로 약점 보강 가능

---

### ⬛ SP5. 경쟁사와 1:1 지도 위 비교

**한 줄 요약:** 내 가게 vs 경쟁사, 상권 어디서 이기고 어디서 지는지 한눈에 파악

**설명:**

- 동일 키워드에 대해 내 매장과 선택한 경쟁사의 순위를 지도 위에서 직접 비교  
- 승리(내가 높음) / 패배(경쟁사가 높음) / 무승부를 색상으로 시각화  
- 경쟁사 대비 취약한 구역을 발견하고 집중 공략 가능

**플랜별:**

- Pro: 최대 5곳 경쟁사 비교 (네이버)  
- Premium: 최대 50곳 경쟁사 비교 (네이버 \+ 구글)

---

### ⬛ SP6. 마케팅 성과(ROI)를 시각적으로 측정한다

**한 줄 요약:** "마케팅 전/후 \[플레이스 순위 지도\] 색상 변화"로 성과를 즉각 확인

**설명:**

- 마케팅 대행사에 맡기거나 직접 마케팅 작업 후, 동일 키워드로 \[플레이스 순위 지도\]을 다시 분석  
- 빨간불 → 노란불 → 초록불로 변화했는지 색상으로 즉시 확인  
- "대행사가 효과 있나요?" 라는 질문에 데이터로 답할 수 있음  
- 감이 아닌 데이터 기반 의사결정

---

### 📬 SP7. 자동 리포트 \+ 카카오 알림톡

**한 줄 요약:** 굳이 접속하지 않아도 카톡으로 순위 변동을 알려드립니다

**설명:**

- 네이버: 원하는 요일(복수 선택) \+ 시간에 자동 크롤링 → 일간 리포트 발송  
- 구글: 주 1회 자동 크롤링 → 주간 리포트 발송  
- 카카오 알림톡으로 결과 요약 발송 → 매일 앱 접속할 필요 없음  
- 사장님은 영업에 집중하고, 맵타민이 매장 순위를 대신 모니터링

---

### ⬛ SP8. 네이버 \+ 구글 동시 지원 (국내 유일)

**한 줄 요약:** 한 플랫폼에서 네이버 지도와 구글 지도 순위를 모두 관리

**설명:**

- 외국인 고객이 많은 업종(관광지 맛집, 호텔, 게스트하우스 등)은 구글 지도 순위도 중요  
- 맵타민 Premium 플랜은 네이버 \+ 구글 지도 \[플레이스 순위 지도\] 동시 제공  
- 국내 경쟁사(애드랭크 등) 대비 구글 지도 분석은 맵타민만의 확실한 차별점

## 3\. 경쟁사(애드랭크, 캐치랭크 등) 대비 포지셔닝

| 비교 항목 | 경쟁사 | 맵타민 |
| :---- | :---- | :---- |
| **분석 방식** | 지역명 키워드의 고정 순위 숫자 추적 | 업종 키워드의 **위치별 순위**를 지도 \[플레이스 순위 지도\]으로 시각화 |
| **알 수 있는 것** | "건대카페" 몇 위인지 | "카페"가 상권 어디서 몇 위인지, **왜** 지역명 순위가 낮은지 |
| **키워트 투자 판단** | 순위 숫자만 제공, 버릴지/집중할지 판단 불가 | \[플레이스 순위 지도\]로 **지역명 순위가 낮아도 투자 가치가 있는지 없는지 판단 가능** |
| **경쟁사 분석** | 리뷰수, 저장수, 블로그 글 수 비교 | 지도 위에서 **어느 구역에서** 경쟁사에게 지고 있는지 |
| **마케팅 방향 제시** | 순위 숫자만 제공 (방향성 없음) | 약한 지역/키워드를 특정하여 **어디에 집중해야 하는지** 제시 |
| **구글 지도** | 미지원 | ✅ 지원 (Premium) |
| **자동 리포트** | 순위 변동 알림 | \[플레이스 순위 지도\] 기반 일간/주간 리포트 \+ 카카오 알림톡 |

### ⬛ SP9. 복잡한 데이터 몰라도 된다 — 색깔만 알면 된다

**한 줄 요약:** SEO 지식 0인 사장님도 5초 만에 현황 파악

**설명:**

-  순위, 좌표, 노출률 등 복잡한 수치를 몰라도 됨  
- 초록 \= 좋음 / 노랑 \= 보통 / 빨강 \= 약함, 단 3가지 색깔로 모든 상황 판단 가능  
- "초록불 늘리면 된다"는 단순한 목표로 사장님이 스스로 전략을 세울 수 있게 됨  
- 대행사나 전문가 없이도 내 매장 SEO 현황을 직접 모니터링 가능

**경쟁사 대비:**  
\- 애드랭크: 숫자와 그래프 → 해석을 위한 학습 필요  
\- 맵타민: 색깔 지도 → 직관적으로 즉시 이해

**마케팅 카피:**

- "마케팅 데이터, 아직도 엑셀로 보시나요? 사장님은 색깔만 확인하세요."  
- "초록불을 늘리세요. 매출도 함께 올라갑니다."

## 4\. 핵심 마케팅 메시지 (한 줄 카피)

"내 가게 순위가 안 오르는 이유, 숫자가 아닌 지도에 답이 있습니다"

### 타겟: 마케팅 비용 효율을 원하는 사장님

"상권 전체에 돈 뿌리지 마세요. 약한 지역만 골라서 집중하세요"

### 타겟: 경쟁사를 이기고 싶은 사장님

"경쟁사를 이기려면, 어디서 지고 있는지부터 지도로 확인하세요"

### 타겟: 상권에 들어온 잠재고객을 붙잡고 싶은 사장님

"'내 근처 맛집' 검색한 고객에게 내 가게가 보이나요? 위치마다 결과가 다릅니다"

### 타겟: 대행사 효과 의심하는 사장님

"대행사 효과 있었나요? 마케팅 전후 \[플레이스 순위 지도\] 색상 변화로 바로 확인하세요"

## 5\. 요약: 맵타민의 본질적 가치

맵타민은 "어디에 마케팅 비용을 쓰고, 어디를 포기해야 하는지"를 지도 위의 색상으로 직관적이고 객관적으로 알려주는 도구입니다.

1. **진단**: 업종 키워드 \[플레이스 순위 지도\]으로 상권 내 내 매장의 실제 영향력을 파악  
2. **판단**: 집중할 키워드 vs 보류할 키워드를 데이터로 구분  
3. **방향**: 약한 지역(빨간불)을 특정하여 마케팅 타겟 설정  
4. **측정**: 마케팅 전후 \[플레이스 순위 지도\] 색상 변화로 ROI 확인
