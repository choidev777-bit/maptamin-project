## 2. 서비스 소개

맵타민은 **네이버 지도·구글 지도에서 내 매장의 검색 순위를 시각적으로 분석**해주는 로컬 SEO(지역 검색 최적화) SaaS입니다.

소상공인 사장님이 특정 키워드로 검색했을 때 내 매장이 몇 위에 노출되는지를 지도 위 그리드(격자) 형태로 보여주며, 경쟁사 대비 순위 현황과 변동 추이를 추적·분석합니다.

### 핵심 기능

| 기능 | 설명 |
|------|------|
| 순위 지도 분석 | 매장 주변 격자(그리드) 좌표별 검색 순위를 지도에 시각화 |
| 키워드 관리 | 관리할 검색 키워드 등록 및 순위 추적 |
| 경쟁사 분석 | 주요 경쟁 매장과의 순위 비교 |
| 자동 주간 보고서 | 매주 순위 변동 현황을 이메일로 자동 발송 |
| 실시간 진단 티켓 | 원하는 시점에 즉시 순위 분석 실행 |

## 3. 사업 모델

맵타민은 **구독형 SaaS + 단건 이용권** 혼합 모델로 운영됩니다.

### (1) 월간 구독 플랜 (정기결제)

| 플랜 | 월 구독료 (VAT 포함) | 주요 기능 |
|------|---------------------|----------|
| 스타터 | 9,900원 | 네이버 지도 분석, 3×3 격자, 키워드 2개, 월 2회 티켓 |
| 프로 | 29,000원 | 네이버 지도 분석, 5×5 격자, 키워드 5개, 경쟁사 3곳, 월 10회 티켓 |
| 프리미엄 | 99,000원 | 네이버+구글 분석, 7×7 격자, 키워드 10개, 경쟁사 10곳, 월 15회 티켓 |

- 결제일 기준 매월 자동 갱신 (빌링키 방식 정기결제)
- 이용자가 해지 신청 전까지 자동 결제 지속

### (2) 실시간 진단 티켓 (단건 결제)

- 구독 플랜에 포함된 월 티켓 외, 추가로 필요한 경우 별도 구매 가능
- 티켓 단가: **1,500원/장 (VAT 포함)**
- 구매 수량 제한 없음 (1장 단위 구매 가능)
- 네이버용·구글용 구분하여 구매

## 5. 결제 흐름

```
[구독 결제]
회원가입 → 플랜 선택 → 카드 등록(빌링키 발급) → 즉시 첫 결제 → 매월 자동 결제

[티켓 단건 결제]
대시보드 접속 → 티켓 구매 → 수량 선택 → 결제 → 티켓 즉시 지급
```
