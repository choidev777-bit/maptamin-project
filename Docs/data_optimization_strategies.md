# 📉 네이버 그리드 데이터 절감 및 보안 전략 보고서 (Final)

> **작성자**: 30년차 개발자 페르소나  
> **목표**: 데이터 절감(90%)과 계정 안전(Security)을 동시에 달성  
> **핵심 원칙**: **"안전한 1MB"** (0.1MB 욕심내다 차단당하지 말자)

---

## 1. �️ 보안/안전 전략: [1요청 1 IP 교체]
> **목표**: "슈퍼맨(Bot)" 탐지 회피

*   **원칙**: 그리드 포인트 1개를 검색할 때마다 **무조건 새로운 IP**를 사용합니다.
*   **이유**:
    *   IP 하나로 3초 만에 500m씩 이동하며 49번 검색하면 **"비정상 이동 패턴"**으로 즉시 차단됩니다.
    *   서로 다른 IP 49개로 검색하여 **"서로 다른 49명이 각자 검색한 것"**처럼 위장해야 안전합니다.
*   **구현**:
    *   **Context Isolation**: 브라우저(엔진)는 켜두되, 탭(Context)을 닫고 새로 열 때마다 프록시 설정을 바꿉니다.

## 2. � 데이터 절감 전략: [리소스 차단]
> **목표**: **20MB → 1~2MB** (90% 이상 절감)

IP를 매번 바꾸면 캐시(Cache)를 못 쓰게 되어 데이터 소모가 큽니다. 이를 방어하기 위해 **불필요한 파일을 아예 받지 않습니다.**

*   **차단 대상 (0 Byte 처리)**:
    1.  **지도 타일 (Map Tiles)**: ⚠️ 가장 중요! (데이터의 80% 차지). 텍스트(가게명) 크롤링에 필요 없는 배경 지도는 차단합니다.
    2.  **이미지**: 가게 음식 사진, 리뷰 사진, 광고 배너.
    3.  **폰트 & 미디어**: 웹폰트, 동영상.
    4.  **트래킹 스크립트**: 광고 추적기.

## 3. 🧠 하이브리드 스크래핑 (Hybrid Architecture) [Ultimate]
> **목표**: **0.1MB** 수준의 데이터 사용량 (지방 흡입) + **100% 성공률**

네이버의 데이터를 가져오는 두 가지 방법을 섞어서 사용합니다.

### 작동 로직 (Flow)
1.  **[1차 시도] JS API 인터셉트 (Fast Track)**
    *   **방식**: 브라우저가 네이버 서버와 통신하는 'JSON 데이터(순위 정보)' 패킷을 중간에 낚아챕니다.
    *   **성공 시**: 화면이 다 그려지기도 전에(JS 로딩 중) 브라우저를 즉시 종료합니다.
    *   **효과**: 데이터 **0.1MB** 소모. (압도적 효율)

2.  **[실패 감지] Fallback Trigger**
    *   만약 일정 시간(3~5초) 안에 약속된 JSON 패킷이 오지 않는다면?
    *   판단: "네이버가 API 주소를 바꿨거나 구조를 변경했다."

3.  **[2차 시도] DOM 스크래핑 (Safety Net)**
    *   **방식**: 당황하지 않고, 이미 로딩된 화면에서 HTML 태그(Selector)를 보고 순위를 찾습니다.
    *   **효과**: 데이터 **2MB** 소모 (리소스 차단 적용 시). 서비스 중단 없음.

4.  **[자동 알림] Developer Alert**
    *   2차 시도로 넘어간 경우, 관리자에게 **"🚨 긴급: API 막힘. HTML 방식으로 수집함"** 알림 발송.

---

## 🏁 최종 실행 아키텍처

1.  **Browser Process (공유)**:
    *   크롬 브라우저 엔진은 하나만 띄워둡니다. (CPU/RAM 절약)
2.  **Grid Loop (반복)**:
    *   **Step 1: New Context**: 새 탭을 열면서 **새로운 IP** 장착.
    *   **Step 2: Resource Block**: 이미지/지도타일 차단 설정.
    *   **Step 3: Search**: 검색 수행 (데이터 1~2MB 소모).
    *   **Step 4: Close Context**: 탭 닫기 (기록 삭제).

이 방식을 사용하면 **비용은 구글 API 대비 1/50 수준**으로 낮추면서도, **보안 안전도**는 최상으로 유지할 수 있습니다.
