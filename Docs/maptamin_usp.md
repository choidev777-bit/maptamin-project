## 기존 도구 vs 맵타민: 근본적 차이

기존 마케팅 도구(블랙키위, 키워드마스터, 스마트플레이스 통계 등)는 **"지금 몇 위인가"** 하나의 숫자를 알려줍니다.

맵타민은 **"어디에서 몇 위이고, 왜 그런지, 어디를 공략해야 하는지"**를 알려줍니다.

기존 도구가 **체온계**라면, 맵타민은 **CT 스캔**입니다.

| | 기존 도구 | 맵타민 |
|---|---|---|
| **데이터** | 키워드당 순위 1개 | 키워드 × 좌표 N개 = 순위 N개 |
| **커버리지** | 지역명 검색만 | 지역명 검색 + 위치기반 업종 검색 |
| **경쟁사** | 내 순위만 | 좌표별 경쟁사 순위까지 |
| **리포팅** | 내가 접속해야 확인 | 자동 크롤링 + 카카오 알림톡 |

## USP 7가지

### USP 1. 한국 최초 네이버 플레이스 그리드 히트맵

네이버 지도에서 업종 키워드 검색 시, n×n 좌표별 순위를 히트맵(초록/노랑/빨강)으로 시각화하는 **한국 최초이자 유일한 서비스**.

구글 기반 Grid Heatmap(LocalFalcon, BrightLocal 등)은 해외에 존재하지만, 한국 로컬 검색 시장의 절대 1위 플랫폼인 네이버 기반은 맵타민뿐.

> **카피 방향**: *"플레이스 순위, 한 개가 아니라 25개입니다"* / *"내 가게 앞에선 1위, 옆 동네에선 30위 — 당신은 이걸 모르고 마케팅하고 있었습니다"*

### USP 2. 두 가지 검색 시나리오를 모두 커버

네이버 플레이스 검색은 두 가지 로직으로 나뉩니다:

- **지역명 포함** ("홍대 카페"): 검색자 위치 무관, 결과 동일
- **지역명 미포함** ("카페", "근처 카페"): 검색자 위치에 따라 결과 상이

기존 도구는 지역명 포함 검색의 순위 1개만 보여줍니다. 맵타민은 **지역명 미포함 업종 키워드의 좌표별 순위 N개**까지 제공합니다.

네이버가 공식적으로 밝힌 "인기도" 로직에 따르면, 지역명+업종 키워드 상위 노출을 위해서는 상권 내에서 업종 키워드 순위가 전반적으로 높아야 합니다. 맵타민은 이것을 정확히 측정합니다.

> **카피 방향**: *"'근처 카페'로 검색했을 때, 내 가게는 어디까지 보일까요?"*

### USP 3. 듀얼 플랫폼 지원 (네이버 + 구글)

하나의 대시보드에서 네이버 플레이스와 구글 맵 순위를 동시 추적. 외국인 관광객/MZ세대 대상 상권(이태원, 명동, 을지로 등)에서 구글 맵 노출은 매출에 직결됩니다.

> **카피 방향**: *"네이버 지도, 구글 맵 — 두 세계의 순위를 한 화면에서"*

### USP 4. 완전 자동화 리포팅 + 카카오 알림톡 발송

사용자가 설정한 요일/시간에 자동 크롤링 후, 결과 요약을 카카오 알림톡으로 즉시 발송합니다.

- 네이버: 선택한 요일마다 일간 리포트
- 구글: 매주 1회 주간 리포트

사장님들은 바쁩니다. 별도 앱 설치 없이, 매일 쓰는 카카오톡으로 순위를 확인할 수 있습니다.

> **카피 방향**: *"매일 아침, 카카오톡으로 받는 내 매장 순위 리포트"* / *"로그인 없이도 마케팅 성과를 확인하세요"*

### USP 5. 경쟁사 비교 히트맵

내 가게와 경쟁사의 순위를 동일 그리드 위에서 1:1 비교합니다.

- 승리(초록): 내가 더 높은 좌표
- 패배(빨강): 경쟁사가 더 높은 좌표

기존 도구는 "내가 5위, 경쟁사가 3위"로 끝나지만, 맵타민은 **어느 좌표에서 이기고 어느 좌표에서 지는지** 공간 차원의 경쟁 지형도를 제공합니다.

> **카피 방향**: *"옆 가게와 순위 전쟁, 지도 위에서 눈으로 확인하세요"*

### USP 6. 데이터 기반 마케팅 의사결정 (히스토리 그래프)

일간/주간 리포트가 누적되면 키워드별 평균 순위 변동 추이를 그래프로 시각화합니다.

두 그래프(업종 키워드 + 지역명 키워드)를 교차 분석하면 다음과 같은 판단이 가능합니다:

| 업종 키워드 | 지역명 키워드 | 의미 | 액션 |
|:---:|:---:|------|------|
| ↑ 상승 | ↑ 상승 | 전반적으로 잘 되고 있음 | 밀어라. 모멘텀 유지 |
| ↑ 상승 | → 정체 | 인기도는 오르는데 지역명에 아직 미반영 | 기다리면 따라올 가능성. 유지 |
| → 정체 | ↓ 하락 | 위험 신호. 경쟁사에 밀리는 중 | 전략 전환 필요 |
| ↓ 하락 | ↓ 하락 | 심각. 즉시 원인 파악 필요 | 리뷰/방문자수/기본기 점검 |

**실전 예시 (선릉역 이자카야 가게 기준)**:
- "룸술집" 한 달 만에 15위→7위 급상승 → 마케팅 리소스 집중 투입하여 모멘텀 유지
- "회식" 한 달째 10위 정체 → 현재 방식이 통하지 않음, 전략 전환 또는 리소스 재배분
- "하이볼" 이미 3~5위 안정권 → 추가 투자 ROI 낮음, 다른 키워드에 리소스 재배분

> **카피 방향**: *"지난달 블로그 체험단, 정말 효과 있었을까요?"* / *"감이 아닌 그래프로 증명하는 마케팅 성과"*

### USP 7. 합리적 가격 설계 (티켓제)

월 9,900원부터 시작. 정기 리포트는 티켓 소모 없이 자동 실행, 실시간 분석만 티켓 차감. 검색 실패 시 자동 환불.

해외 Grid Heatmap 서비스는 최저 $29~$99/월. 블로그 체험단 1건(5~10만원)보다 저렴하면서 더 정교한 인사이트를 제공합니다.

> **카피 방향**: *"체험단 한 건 비용으로, 한 달 내내 순위를 추적하세요"* / *"월 9,900원으로 시작하는 데이터 마케팅"*

## 맵타민을 사용하면 가능한 것들

1. **마케팅 "타겟 지역" 설정** — 히트맵에서 빨간색(하위권) 좌표를 식별하고 해당 구역에 마케팅 집중
2. **마케팅 효과의 위치 단위 검증** — 체험단/리뷰 이벤트 전후 특정 좌표의 순위 변화 비교
3. **내 상권의 실질 "영향력 반경" 파악** — 초록색 좌표의 분포 = 내 가게의 실질 노출 범위
4. **경쟁사와의 "영역 싸움" 시각화** — 어떤 좌표에서 지고 있는지 정확히 파악
5. **대행사 성과를 직접 검증** — 히트맵 색상 변화로 마케팅 약속의 실효성 즉각 판단
6. **키워드별 투자 우선순위 결정** — 상승 중인 키워드에 밀고, 정체된 키워드는 전략 전환
7. **시즌별/요일별 노출 패턴 파악** — 일간 데이터 누적으로 트렌드 분석 가능
