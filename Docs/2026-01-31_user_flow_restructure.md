# 기획 변경: User Flow 및 페이지 구성 개편안

## 1. 개요
본 문서는 2026-01-31 요청된 유저 플로우 및 네비게이션 구조 변경 사항을 정리합니다.

---

## 2. 신규 가입 유저 플로우 (New User Flow)

### 1) 진입
- 회원가입 완료 후 대시보드 진입.

### 2) 초기 대시보드 상태
- **구성**: 화면에 2개의 가로형 카드가 배치됨.
  - **상단 카드**: "네이버"
  - **하단 카드**: "구글"
- **초기 액션**: 각 카드에 "사장님의 매장을 선택해주세요" 버튼 존재.

### 3) 매장 선택 프로세스 (네이버/구글 공통)
1. "사장님의 매장을 선택해주세요" 버튼 클릭.
2. **지도 장소 검색 팝업** 노출 (플랫폼에 맞는 지도 API 사용).
3. 장소 검색 및 선택 후 "선택" 버튼 클릭.
4. **경고 메시지**: "한 번 선택하면 30일간 변경할 수 없습니다."
5. 확인 시 해당 매장으로 고정.

### 4) 매장 선택 후 상태
- 카드에 "아직 검색 기록이 없습니다." 문구 표시.

### 5) 검색 데이터 누적 후 상태
- 각 카드 상단에 **검색 키워드**들이 나열됨.
- 키워드 클릭 시: 해당 키워드의 **날짜별 평균 순위 변화 그래프**가 카드 내에 표시됨.

## 3. 네비게이션 및 페이지 구성 (GNB)

### 1) 데스크탑 GNB 구조
1. **대시보드**
2. **내 가게 순위 검색** (Dropdown)
3. **경쟁사 순위 검색** (Dropdown)
4. **설정**

### 2) 메뉴별 상세 동작

#### A. 대시보드
- 클릭 시 대시보드 페이지로 이동.

#### B. 내 가게 순위 검색
하단 서브 메뉴 노출:
1. **네이버 지도 검색**
   - **이동**: 네이버 검색 비즈니스 선택 페이지.
   - **변경점**: 기존의 "내 가게 / 경쟁사에서 선택" 옵션 삭제 (설정된 내 가게로 자동 진행을 의미하는 것으로 보임).
2. **구글 지도 검색**
   - **이동**: 구글 검색 기능 페이지.

#### C. 경쟁사 순위 검색
하단 서브 메뉴 노출:
1. **네이버 지도 검색**
   - **미설정 시**: "경쟁사를 선택해주세요" 안내 및 슬롯 노출 (슬롯 수는 플랜에 따름).
   - **경쟁사 설정**:
     - 슬롯 클릭 -> **네이버** 지도 검색 팝업 -> 장소 선택 -> "30일간 변경 불가" 메시지.
   - **설정 완료 후**: 슬롯 우측에 버튼 2개 생성.
     - `[검색]`: 그리드 검색 페이지로 이동.
     - `[기록]`: 해당 경쟁사 검색 기록 리스트 페이지로 이동 -> 리스트 클릭 시 결과 페이지 이동.

2. **구글 지도 검색**
   - **미설정 시**: "경쟁사를 선택해주세요" 안내 및 슬롯 노출 (슬롯 수는 플랜에 따름).
   - **경쟁사 설정**:
     - **구글** 지도 검색 팝업 (사용자 확인 완료: 네이버 오타 수정)
     - 장소 선택 -> "30일간 변경 불가" 메시지.
   - **설정 완료 후**:
     - `[검색]`: 그리드 검색 페이지로 이동.
     - `[기록]`: 해당 경쟁사 검색 기록 리스트 페이지로 이동 -> 리스트 클릭 시 결과 페이지 이동.

## 4. 확인 및 질문 사항 (Q&A) - [답변 완료]

### Q1. 구글 경쟁사 등록 시 팝업
- **질문**: 구글 경쟁사이므로 **구글 지도 검색 팝업**을 띄우는 것이 맞는지요?
- **답변**: 네, 맞습니다. (오타 수정됨)

### Q2. '내 가게 순위 검색' 시 동작
- **질문**: 대시보드에서 고정한 "내 가게" 정보가 자동으로 입력된 상태로 검색 설정(키워드 입력 등) 단계로 바로 넘어간다는 뜻인가요?
- **답변**: 네, 맞습니다.

### Q3. 대시보드 그래프
- **질문**: 이 그래프가 페이지 이동 없이 카드 내부(또는 모달)에서 즉시 보여지는 인터랙션인가요?
- **답변**: 네, 맞습니다. 페이지 이동 없이 카드 내부에서 즉시 펼쳐집니다.
