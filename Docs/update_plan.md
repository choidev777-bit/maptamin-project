4. 경쟁사 분석 기능 수정

기존 “경쟁사 순위 검색” 기능을 삭제합니다.

경쟁사 분석 기능으로 수정합니다.

1) 현재 '내 가게'의 순위만 보여주는 그리드 맵(히트맵)에 경쟁사와의 순위 비교 기능을 추가하고 싶습니다. 사용자가 특정 경쟁사를 선택하면, 각 그리드 지점마다 "내가 이겼는지(Win)", **"졌는지(Lose)"**를 색상으로 시각화하여 보여주는 기능입니다.

2) SearchResult 타입에 이미 competitors (상위 업체 리스트) 배열이 포함되어 있습니다.
따라서 추가 크롤링이나 비용 발생 없이, 기존 데이터를 활용하여 프론트엔드에서 필터링 및 시각화만 하면 됩니다.


3) UI 변경
그리드맵 결과물 밑에 경쟁사 분석 지도를 만듭니다.
검색한 키워드 목록 클릭하면 결과물이 바뀝니다.
경쟁사 선택하는 드롭다운이 있습니다.

4) 히트맵 시각화 로직
각 그리드(UniquePosition)마다 내 순위(myRank)와 선택한 경쟁사의 순위(competitorRank)를 비교합니다.
색상 및 마커 변경:


WIN (초록색): myRank < competitorRank (내가 더 상위) 또는 competitorRank가 없을 때.
LOSE (빨간색): myRank > competitorRank (내가 더 하위) 또는 myRank가 없을 때.
마커 텍스트를 순위 숫자 대신 "승", "패" 텍스트로 변경합니다. (또는 아이콘)

각 그리드 클릭하면 내 가게가 몇위이고, 선택한 경쟁사가 몇위인지 보여줍니다.

5) 범례(Legend) 업데이트
비교 모드일 때는 하단 범례를 [🟢 승리], [🔴 패배]로 변경하여 보여줍니다.

5. 1주일에 한번씩 리포트를 보내주기 때문에 이 기준으로 평균 순위 변동 그래프를 보여주고 싶습니다. (관리 키워드별) (실시간 진단 티켓으로 검색한 결과는 제외)
