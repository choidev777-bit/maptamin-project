## 1. Kakao Developers 콘솔 설정

> **목적**: 카카오 OAuth 로그인 (Google 로그인 → 카카오 로그인 전환)

### 1-1. 앱 생성

1. [Kakao Developers](https://developers.kakao.com/) 로그인
2. **내 애플리케이션** → **애플리케이션 추가하기**
3. 정보 입력:

| 항목 | 입력값 |
|------|--------|
| 앱 이름 | `맵타민` |
| 사업자명 | 등록된 사업자명 |
| 카테고리 | `비즈니스` > `마케팅/광고` |

### 1-2. 앱 키 확인

**위치**: 앱 설정 → **앱 키**

| 키 종류 | Supabase 매핑 |
|---------|---------------|
| **REST API 키** | Supabase Client ID |
| Admin 키 | 미사용 (솔라피가 대신 처리) |

> [!IMPORTANT]  
> **REST API 키** = Supabase의 `Client ID`. JavaScript 키와 혼동 금지.

### 1-3. 플랫폼 등록

**위치**: 앱 설정 → **플랫폼** → **Web**

```
https://your-project-domain.com
http://localhost:3000
```

### 1-4. 카카오 로그인 활성화

**위치**: 제품 설정 → **카카오 로그인** → 상태 `ON`

### 1-5. Redirect URI 등록

**위치**: 제품 설정 → **카카오 로그인** → **Redirect URI**

```
https://<YOUR_SUPABASE_PROJECT_REF>.supabase.co/auth/v1/callback
```

### 1-6. Client Secret 생성

**위치**: 제품 설정 → **카카오 로그인** → **보안** → 코드 생성 → 활성화 `사용함`

> [!CAUTION]  
> Client Secret은 한 번만 표시됩니다. 즉시 저장하세요.

### 1-7. 동의 항목 설정

**위치**: 제품 설정 → **카카오 로그인** → **동의항목**

| 항목 | 설정 |
|------|------|
| 닉네임 | `필수 동의` |
| 프로필 사진 | `선택 동의` |
| 카카오 계정(이메일) | `필수 동의` |

> [!NOTE]  
> 이메일 `필수 동의`는 **사업자 앱**만 가능.  
> **위치**: 앱 설정 → **비즈니스** → 사업자 정보 등록 완료 필요.

## 2. Supabase 대시보드 설정

**위치**: Authentication → Providers → **Kakao** → `ON`

| 필드 | 값 |
|------|-----|

### 2-2. Redirect URL 설정

**위치**: Authentication → URL Configuration

| 항목 | 값 |
|------|-----|

| Redirect URLs | `https://your-project-domain.com/**`, `http://localhost:3000/**` |

## 3. 솔라피 설정

> **목적**: 카카오 알림톡 발송 (전화번호 기반)  
> **솔라피 = 카카오 알림톡 발송 대행사**. 우리 서버 → 솔라피 API → 카카오 서버 → 사용자 카톡

### 3-1. 솔라피 가입

1. [솔라피](https://solapi.com/) 가입
2. 사업자 인증 (사업자등록증 업로드)

### 3-2. API Key 발급

**위치**: 솔라피 대시보드 → **개발/연동** → **API Key 관리**

| 항목 | 환경 변수 |
|------|----------|
| API Key | `SOLAPI_API_KEY` |
| API Secret | `SOLAPI_API_SECRET` |

### 3-3. 발신번호 등록

**위치**: 솔라피 대시보드 → **발신번호 관리**

- 사업자 대표번호 또는 휴대폰 번호 등록
- **인증 절차** 필요 (ARS 또는 서류 제출)
- 등록 완료 후 → 환경변수 `SOLAPI_SENDER_NUMBER`에 저장

### 3-4. 카카오톡 채널 연동

**위치**: 솔라피 대시보드 → **카카오톡** → **채널 연동**

1. 기존에 개설한 **카카오 비즈니스 채널** 검색 → 연동
2. 연동 완료 시 **발신프로필 ID (pfId)** 발급
3. → 환경변수 `SOLAPI_PFID`에 저장

> [!IMPORTANT]  
> 이 **pfId**가 알림톡 발송 시 필수 파라미터입니다. 채널 연동 없이는 발송 불가.

## 4. 알림톡 템플릿 등록 & 심사

> **심사 주체**: 카카오 (솔라피가 대신 제출)  
> **소요 시간**: 영업일 1~3일  
> **핵심**: 정보성 메시지만 가능. 광고 문구 포함 시 반려.

### 4-1. 템플릿 등록 방법

**위치**: 솔라피 대시보드 → **카카오톡** → **알림톡 템플릿 관리** → **템플릿 등록**

### 4-2. 웰컴 리포트 템플릿

| 항목 | 값 |
|------|-----|
| 템플릿 이름 | `WELCOME_REPORT` |
| 카테고리 | `서비스/업데이트 안내` |
| 메시지 유형 | `기본 텍스트` |

**본문**:
```
[맵타민] 웰컴 리포트가 도착했습니다.

안녕하세요, #{가게명} 사장님!
첫 번째 플레이스 순위 지도가 완성되었습니다.

결과 확인하기:
#{리포트URL}
```

**버튼**:
- 타입: `웹링크`
- 버튼명: `리포트 확인하기`
- URL: `#{리포트URL}`

### 4-3. 주간 리포트 템플릿

| 항목 | 값 |
|------|-----|
| 템플릿 이름 | `WEEKLY_REPORT` |
| 카테고리 | `서비스/업데이트 안내` |
| 메시지 유형 | `기본 텍스트` |

**본문**:
```
[맵타민] 주간 리포트

#{가게명}의 이번 주 플레이스 순위 지도를 보내드립니다.

결과 확인하기:
#{리포트URL}
```

**버튼**:
- 타입: `웹링크`
- 버튼명: `리포트 확인하기`
- URL: `#{리포트URL}`

### 4-4. 심사 팁

> [!WARNING]  
> 아래 내용이 포함되면 **반려**됩니다:
> - "할인", "무료", "이벤트", "한정" 등 **광고성 문구**
> - 이모지 과다 사용
> - 카카오 정책 위반 표현

> [!TIP]  
> - 본문은 **사용자가 요청한 정보의 전달**이어야 합니다
> - "구독하신 서비스의 결과가 도착했습니다" 형태가 가장 안전
> - 변수(`#{가게명}`)는 실제 데이터로 치환되므로 심사 시 예시값 제출

## 5. 환경 변수 총정리

### `.env.local`에 추가할 변수

```env
# ──────────────────────────────────────
# Kakao OAuth (Supabase 대시보드에 직접 입력)
# ──────────────────────────────────────
# REST API 키, Client Secret → Supabase에만 등록
# .env.local에는 저장 불필요

# ──────────────────────────────────────
# 솔라피 (Solapi) — 알림톡 발송용
# ──────────────────────────────────────
SOLAPI_API_KEY=your_solapi_api_key
SOLAPI_API_SECRET=your_solapi_api_secret
SOLAPI_SENDER_NUMBER=01012345678
SOLAPI_PFID=your_kakao_channel_pfid

# ──────────────────────────────────────
# 알림톡 템플릿 코드 (심사 승인 후 발급)
# ──────────────────────────────────────
KAKAO_TEMPLATE_WELCOME=your_welcome_template_code
KAKAO_TEMPLATE_WEEKLY=your_weekly_template_code

# ──────────────────────────────────────
# 사이트 URL (알림톡 내 링크용)
# ──────────────────────────────────────
SITE_URL=https://your-project-domain.com
```

### 변수 출처 요약

| 변수 | 출처 | 용도 |
|------|------|------|
| `SOLAPI_API_KEY` | 솔라피 대시보드 → API Key 관리 | SDK 인증 |
| `SOLAPI_API_SECRET` | 솔라피 대시보드 → API Key 관리 | SDK 인증 |
| `SOLAPI_SENDER_NUMBER` | 솔라피 대시보드 → 발신번호 관리 | 발신 번호 |
| `SOLAPI_PFID` | 솔라피 → 카카오 채널 연동 후 발급 | 카카오 발신프로필 |
| `KAKAO_TEMPLATE_WELCOME` | 솔라피 → 알림톡 템플릿 심사 승인 후 | 웰컴 리포트 |
| `KAKAO_TEMPLATE_WEEKLY` | 솔라피 → 알림톡 템플릿 심사 승인 후 | 주간 리포트 |
| `SITE_URL` | 직접 설정 | 알림톡 내 링크 |

## 6. Redirect URI 요약

| 환경 | Redirect URI |
|------|-------------|
| **프로덕션** | `https://<PROJECT_REF>.supabase.co/auth/v1/callback` |

**콜백 흐름**:
```
사용자 → 카카오 로그인 → 카카오 인증 서버
  → Supabase Callback (auth/v1/callback)
  → Supabase 세션 생성
  → 앱 callback route (/auth/callback)
  → 대시보드 리디렉트
```
